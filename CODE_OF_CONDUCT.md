# Code of conduct

TraceJIT is a technical project. Criticism of the safety model, the benchmarks, and the code is expected and welcome.

- Discuss the work. Do not attack the person.
- Do not harass, threaten, or post someone else's private information.
- Do not open issues or pull requests that weaken a classification in order to make a benchmark pass.
- Do not ask people to star the repository.

The maintainer may edit or hide comments, issues, and pull requests that break these rules, and may block repeat abuse. This is a project policy, not a claim that a foundation is mediating disputes.
